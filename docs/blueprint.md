# **App Name**: CertiSeal

## Core Features:

- Certificate Upload: User uploads a certificate PDF.
- Data Input: User inputs expiry date, company name, company ID, and work ID.
- QR Application & Positioning: Apply a QR code to the uploaded certificate based on user input and make the QR code movable within the certificate preview.
- Download Certificate: Allow users to save the certificate with the QR code and download the updated PDF.
- Certificate Search: Search for certificates using a Work ID.
- Certificate Validation and Display: Display certificate information and status (valid/expired) based on the expiry date. If the certificate is expired, a message stating the expiration date will be shown, and the certificate will not be displayed.

## Style Guidelines:

- Primary color: A calm, authoritative blue (#4A86B4), reflecting trust and security.
- Background color: A desaturated light blue (#E0F0F8) creates a clean, professional backdrop.
- Accent color: A warm orange (#E58E44) highlights important actions and notifications.
- Font pairing: 'Poppins' (sans-serif) for headers, conveying a contemporary and clear aesthetic, and 'PT Sans' (sans-serif) for body text, offering readability.
- Tabs for 'Apply QR Code' and 'Verification' to provide a clear separation of functionality.
- Use simple, professional icons for file uploads, downloads, and search functions.
